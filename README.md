# ИБ ТЕСТ

Автономная Windows-программа для тестирования сотрудников на знание требований информационной безопасности. Администратор загружает приказы, локальная языковая модель выделяет требования и составляет вопросы, администратор их утверждает, сотрудник вводит ФИО и подразделение и получает случайный тест из 30 вопросов. Интернет в повседневной работе не нужен.

Архитектура, схема БД, алгоритмы генерации и сравнения редакций — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Возможности

- Документы PDF (в том числе сканы — через OCR), DOCX (с автонумерацией Word), DOC, RTF, TXT, изображения. Русский и казахский язык определяются автоматически, казахские буквы сохраняются во всех форматах, отчётах и экспорте.
- Генерация вопросов локальной моделью GGUF (llama.cpp, CPU/GPU): 4 типа вопросов, 3 уровня сложности, ссылка на пункт и дословную цитату, программная проверка опоры на текст и дублей, самопроверка моделью.
- Проверка и утверждение: просмотр пункта-основания, правка, групповое утверждение, отклонение, повторный AI-анализ. Статусы: черновик, на проверке, утверждён, отклонён, устарел.
- Редакции приказов: сравнение по пунктам (добавлено / изменено / удалено / без изменений / ручная проверка), перенос и актуализация вопросов, активация и восстановление редакций, полная история.
- Тестирование: один вопрос на экране, навигация, прогресс, таймер, подтверждение завершения, балансировка по разделам и сложности, профили с несколькими приказами.
- Неизменяемые результаты со снимком вопросов и контрольной суммой; карточка сотрудника с динамикой; контроль прохождения (сдали / не сдали / не проходили / нужно пересдать после изменения требований).
- Аналитика с графиками, отчёты за день / неделю / месяц / период / по подразделению / приказу / сотруднику; экспорт Excel и PDF, печать.
- Администраторы с паролями scrypt, журнал действий, автовыход, резервные копии по расписанию с проверкой целостности и шифрованием, восстановление с автоматической страховочной копией.
- Интерфейс на русском и казахском.

## Установка (пользователь)

1. Запустить `IBTest_Setup_<версия>.exe` (Windows 10/11 x64, права администратора).
2. Языковая модель: запустить `IBTest_Model_Setup.exe` **или** положить файл `.gguf` в папку `models` рядом с `IBTest_Setup.exe` до установки **или** указать файл в «Настройки → Локальная модель».
3. При первом запуске создать учётную запись администратора.

Ярлык «ИБ ТЕСТ — тестирование сотрудников» открывает полноэкранный режим для сотрудников.

### Какую модель выбрать

| Модель (GGUF, Q4_K_M) | Размер | ОЗУ | Комментарий |
|---|---|---|---|
| Qwen2.5-7B-Instruct | ~4,7 ГБ | 16 ГБ | хороший русский, приемлемый казахский; лицензия Apache 2.0 |
| ISSAI Llama-3.1-KazLLM-1.0-8B (GGUF4) | ~4,9 ГБ | 16 ГБ | лучшая из открытых для казахского языка; лицензия CC BY-NC 4.0 — проверьте допустимость использования в вашей организации |
| Модели 3–4B | 2–3 ГБ | 8 ГБ | работают на слабых ПК, качество вопросов ниже — особенно важно утверждение |

Кнопка «Проверить совместимость» в настройках показывает ОЗУ, GPU, параметры модели и предупреждения. Анализ одного приказа на CPU занимает от десятков минут до нескольких часов в зависимости от объёма и процессора; с GPU (сборка `-Gpu cuda`) — в разы быстрее.

## Сборка (разработчик)

### Вариант А — в облаке GitHub (на своём компьютере ничего ставить не нужно)

1. Создайте репозиторий на github.com (можно приватный) и загрузите в него содержимое папки `ib_test` (Add file → Upload files, папку `.github` тоже).
2. Вкладка **Actions** → **Build IBTest installer** → **Run workflow**.
3. Через 20–40 минут в запуске появится артефакт **IBTest-installer** с `IBTest_Setup_1.0.0.exe` (и `build.log`, если что-то пошло не так).

### Вариант Б — на своём компьютере


На компьютере сборки Windows 10/11 x64: Python 3.12, Inno Setup 6.3+, интернет.

```bat
installer\build.bat                 :: CPU-сборка llama.cpp
installer\build.bat -Gpu cuda       :: с поддержкой NVIDIA CUDA 12
installer\build.bat -ModelFile D:\models\qwen2.5-7b-instruct-q4_k_m.gguf -ModelName "Qwen2.5 7B"
```

Журнал сборки: `build\build.log`. Если llama-cpp-python не находит готового пакета для вашей версии Python, pip пытается собрать его из исходников — для этого нужны Build Tools for Visual Studio; проще использовать вариант А.

Скрипт ставит зависимости, загружает Tesseract с языками rus/kaz/eng и VC++ Runtime, запускает автотесты, собирает EXE, выполняет `IBTest.exe --selftest` и собирает установщики в `dist\installer`.

Запуск из исходников:

```bat
py -3.12 -m pip install -r requirements-dev.txt --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu
py -3.12 main.py            :: обычный режим
py -3.12 main.py --kiosk    :: режим сотрудника
py -3.12 -m pytest tests    :: автотесты
```

## Диагностика

- `IBTest.exe --selftest отчёт.txt` — проверка Qt, БД, казахских символов, DOCX/PDF, отчётов, llama.cpp и OCR.
- Журнал: `C:\ProgramData\IBTest\logs\ibtest.log`.
- Данные: `C:\ProgramData\IBTest` (база `ib_test.db`, `documents`, `backups`, `models`).

## Структура

```
main.py                    точка входа (--kiosk, --selftest)
ibtest/
  app_context.py           сборка сервисов
  selftest.py              самопроверка установки
  config/                  пути данных, настройки
  database/                подключение SQLite, миграции
  models/                  типы и перечисления
  services/                document_parser, ocr, language, ai_engine, question_generator, version_comparator,
                           test_engine, analytics, report_generator, backup, security, documents, questions, employees
  ui/                      main_window, pages (12 разделов + режим сотрудника), dialogs, widgets, theme, workers
  localization/            ru.py, kk.py
  assets/                  иконка, шрифты DejaVu (казахские буквы в PDF)
tests/                     автотесты (pytest)
installer/                 build.ps1, ibtest.spec (PyInstaller), ibtest.iss, ibtest_model.iss (Inno Setup)
docs/                      архитектура
```
